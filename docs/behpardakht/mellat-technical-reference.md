# Behpardakht Mellat IPG Technical Specification (مستندات فنی به پرداخت ملت)

## Overview (نمای کلی)
درگاه پرداخت اینترنتی به‌پرداخت ملت (BPM / Shaparak) بر پایه پروتکل **SOAP 1.1 / WSDL** پیاده‌سازی شده است.
واحد پول پیش‌فرض سیستم **ریال (IRR)** می‌باشد.

---

## 1. نشانی‌های سرویس و وب‌سرویس‌ها (Endpoints)

- **WSDL URL**:
  `https://bpm.shaparak.ir/pgwchannel/services/pgw?wsdl`
- **Service Endpoint**:
  `https://bpm.shaparak.ir/pgwchannel/services/pgw`
- **XML Namespace (TargetNamespace)**:
  `http://interfaces.core.sw.bps.com/`
- **Payment Gateway Redirect (شاپرک)**:
  `https://bpm.shaparak.ir/pgwchannel/startpay.mellat`

---

## 2. مشخصات متدهای اصلی (Operations)

### 2.1 درخواست تراکنش (`bpPayRequest`)
پذیرنده ابتدا این متد را فراخوانی می‌کند تا شناسه ارجاع (`RefId`) دریافت کند.

#### Request Parameters
| پارامتر | نوع داده | الزامی | توضیحات |
|---|---|---|---|
| `terminalId` | `long` | بله | شماره پایانه پذیرنده |
| `userName` | `string` | بله | نام کاربری پایانه |
| `userPassword` | `string` | بله | رمز عبور پایانه |
| `orderId` | `long` | بله | شماره سفارش فاکتور (یکتا در سمت پذیرنده) |
| `amount` | `long` | بله | مبلغ تراکنش به ریال |
| `localDate` | `string` | بله | تاریخ جاری سیستم با فرمت `YYYYMMDD` (مثال: `20260924`) |
| `localTime` | `string` | بله | زمان جاری سیستم با فرمت `HHMMSS` (مثال: `143015`) |
| `additionalData` | `string` | خیر | اطلاعات تکمیلی دلخواه (حداکثر ۱۰۰۰ کاراکتر) |
| `callBackUrl` | `string` | بله | آدرس بازگشت خریدار پس از پرداخت |
| `payerId` | `long` | خیر | شناسه خریدار (اختیاری، معمولاً `0`) |

#### Response Format (نکته حیاتی سازگاری)
پاسخ متد `bpPayRequestResponse` در قالب یک رشته بازگردانده می‌شود (`return`):
- در صورت موفقیت: `0,<RefId>` (مثال: `0,1234567890123456`)
- در صورت خطا: `<ResCode>` (مثال: `41` یا `11`)

*کتابخانه‌های واقعی کلاینت (SDKها) مقدار خروجی را با `split(',')` تفکیک می‌کنند.*

---

### 2.2 هدایت کاربر به درگاه (Payment Redirect)
کاربر با یک فرم خودکار **POST** به آدرس شاپرک هدایت می‌شود:
- **Action**: `https://bpm.shaparak.ir/pgwchannel/startpay.mellat`
- **Method**: `POST`
- **Form Hidden Field**:
  - `RefId`: شناسه عددی دریافت شده از `bpPayRequest`
  - (اختیاری) `MobileNo`: شماره موبایل مشتری جهت تکمیل خودکار اطلاعات کارت

---

### 2.3 بازگشت از درگاه به پذیرنده (Callback)
پس از انجام عملیات توسط خریدار در صفحه شاپرک، کاربر از طریق متد **POST** به آدرس `callBackUrl` فرستاده می‌شود.

#### POST Payload Parameters
| فیلد | نوع | توضیحات |
|---|---|---|
| `RefId` | `string` | همان شناسه‌ای که در `bpPayRequest` تحویل داده شد |
| `ResCode` | `string` | کد وضعیت بازگشت از درگاه (`0` یعنی پرداخت کارت موفقیت‌آمیز بوده است) |
| `SaleOrderId` | `string` | شماره سفارش فاکتور پذیرنده (`orderId`) |
| `SaleReferenceId` | `string` | شماره پیگیری یکتای بانکی تراکنش خرید در شاپرک |
| `CardHolderPan` | `string` | شماره کارت ماسک‌شده خریدار (مثال: `610433******1234`) |
| `CardHolderInfo` | `string` | اطلاعات تکمیلی دارنده کارت (در صورت فعال بودن) |

---

### 2.4 تایید تراکنش (`bpVerifyRequest`)
پس از بازگشت موفق خریدار با `ResCode=0`، پذیرنده موظف است حداکثر ظرف چند دقیقه متد `bpVerifyRequest` را فراخوانی کند، در غیر این صورت پول به کارت مشتری عودت داده می‌شود.

#### Request Parameters
| پارامتر | نوع | توضیحات |
|---|---|---|
| `terminalId` | `long` | شماره پایانه |
| `userName` | `string` | نام کاربری پایانه |
| `userPassword` | `string` | رمز عبور پایانه |
| `orderId` | `long` | همان شماره سفارش فاکتور اولیه |
| `saleOrderId` | `long` | شماره سفارشی که در Callback بازگشت داده شد |
| `saleReferenceId`| `long` | شماره پیگیری تراکنش خرید دریافت شده در Callback |

#### Response Format
- موفقیت: `"0"`
- خطا: کد خطای بازگشتی (مثال `"43"` یعنی تراکنش قبلاً وریفای شده است)

---

### 2.5 تسویه و واریز (`bpSettleRequest`)
جهت نهایی کردن و قطعی کردن تسویه مالی تراکنش.
پارامترها مشابه `bpVerifyRequest` هستند (`orderId`, `saleOrderId`, `saleReferenceId`).
- پاسخ موفقیت: `"0"` یا کد `45` (قبلاً ستل شده است).

---

### 2.6 استعلام تراکنش (`bpInquiryRequest`)
اگر پس از کسر وجه از حساب مشتری پاسخی از درگاه دریافت نشد، از این متد برای بررسی وضعیت خرید استفاده می‌شود.
- پارامترها: `terminalId`, `userName`, `userPassword`, `orderId`, `saleOrderId`, `saleReferenceId`.
- پاسخ موفقیت: `"0"`

---

### 2.7 عودت وجه / ریورس (`bpReversalRequest`)
برای لغو و استرداد آنی وجه به کارت مشتری قبل از تسویه نهایی (در بازه مجاز شاپرک).
- پارامترها: `terminalId`, `userName`, `userPassword`, `orderId`, `saleOrderId`, `saleReferenceId`.
- پاسخ موفقیت: `"0"`

---

## 3. جدول کدهای بازگشتی به پرداخت ملت (`ResCode`)

| کد (`ResCode`) | شرح وضعیت |
|---|---|
| `0` | تراکنش با موفقیت انجام شد (تراکنش موفق) |
| `11` | شماره کارت نامعتبر است |
| `12` | موجودی حساب کافی نیست |
| `13` | رمز نادرست است |
| `14` | تعداد دفعات ورود رمز غلط بیش از حد مجاز است |
| `15` | کارت نامعتبر است |
| `16` | دفعات برداشت بیش از حد مجاز است |
| `17` | کاربر از انجام تراکنش منصرف شده است |
| `18` | تاریخ انقضای کارت گذشته است |
| `19` | مبلغ برداشت بیش از حد مجاز است |
| `111` | صادر کننده کارت نامعتبر است |
| `112` | خطای سوییچ صادر کننده کارت |
| `113` | پاسخی از صادر کننده کارت دریافت نشد |
| `114` | دارنده این کارت مجاز به انجام این تراکنش نیست |
| `21` | پذیرنده نامعتبر است |
| `22` | خطای امنیتی رخ داده است |
| `23` | اطلاعات امنیتی پذیرنده نامعتبر است |
| `24` | اطلاعات کاربری پذیرنده نامعتبر است |
| `25` | مبلغ نامعتبر است |
| `31` | پاسخ نامعتبر است |
| `32` | فرمت اطلاعات وارد شده صحیح نمی‌باشد |
| `33` | حساب نامعتبر است |
| `34` | خطای سیستمی |
| `35` | تاریخ نامعتبر است |
| `41` | شماره درخواست تکراری است (`orderId` تکراری) |
| `42` | تراکنش Sale یافت نشد |
| `43` | قبلا درخواست Verify داده شده است |
| `44` | درخواست Verify یافت نشد |
| `45` | تراکنش قبلاً Settle شده است |
| `46` | تراکنش Settle نشده است |
| `47` | تراکنش Settle یافت نشد |
| `48` | تراکنش Reverse شده است |
| `49` | تراکنش Refund یافت نشد |
| `412` | شناسه قبض نادرست است |
| `413` | شناسه پرداخت نادرست است |
| `414` | سازمان صادر کننده قبض نامعتبر است |
| `415` | زمان جلسه کاری به پایان رسیده است (Timeout) |
| `416` | خطا در ثبت اطلاعات |
| `417` | شناسه پرداخت کننده نامعتبر است |
| `418` | اشکال در تعریف اطلاعات مشتری |
| `419` | تعداد دفعات ورود اطلاعات از حد مجاز گذشته است |
| `421` | IP نامعتبر است |
| `51` | تراکنش تکراری است |
| `54` | تراکنش مرجع موجود نیست |
| `55` | تراکنش نامعتبر است |
| `61` | خطا در واریز |
